# Nyx Picks

Data-driven NFL predictions from the Nyx power-rating model: win probabilities, fair moneylines, model spreads vs Vegas, and projected scores.

- Model: net EPA/play, sack differential, turnover differential, net passing, 3rd-down rate, rushing — weighted, with starting-QB injury adjustments.
- Graded publicly every week (record, Brier score, spread-flag hit rate).
- Static site: `index.html` at the repo root, generated from the model outputs in `~/workspace/nfl-research/predictor` (local) and refreshed weekly.

For entertainment and information only — model estimates, not betting advice.
